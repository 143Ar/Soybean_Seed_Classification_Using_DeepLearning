# Soybean_Seed_Classification_Using_DeepLearning
🌱 Project Overview

This project focuses on Soybean Seed Classification using Deep Learning and Transfer Learning techniques. The objective is to automatically classify soybean seeds into different quality categories from images, reducing manual inspection and improving efficiency in agricultural quality assessment.

The model was trained using the Soybean Seeds Dataset from Kaggle and achieved a validation accuracy of approximately 87% using EfficientNetB0.

📌 Features
Image classification of soybean seeds
Transfer Learning with EfficientNetB0
Data Augmentation using ImageDataGenerator
Class Weight balancing
Early Stopping & Model Checkpointing
Performance evaluation using Confusion Matrix and Classification Report
Streamlit Web Application for prediction
